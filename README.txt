1.0 Introduction
/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/
This application provides a means for a user to generate sequences of DTMF
tones for the purpose of dialing phone numbers on early PSTN systems. The
generated tones are currently those generated by a bluebox. The keyboard
mapping between typed characters and generated tones is illustrated in
the table that follows:

Keyboard Character |  Frequency 1 | Frequency 2 |  Amplitude 1 | Amplitude 2
     1             |    700Hz     |   900Hz     |     0.35   |     0.35 
     2             |    700Hz     |  1100Hz     |     0.35   |     0.35 
     3             |    900Hz     |  1100Hz     |     0.35   |     0.35 
     4             |    700Hz     |  1300Hz     |     0.35   |     0.35 
     5             |    900Hz     |  1300Hz     |     0.35   |     0.35 
     6             |   1100Hz     |  1300Hz     |     0.35   |     0.35 
     7             |    700Hz     |  1500Hz     |     0.35   |     0.35 
     8             |    900Hz     |  1500Hz     |     0.35   |     0.35 
     9             |   1100Hz     |  1500Hz     |     0.35   |     0.35 
     0             |   1300Hz     |  1500Hz     |     0.35   |     0.35 
     s (STart)     |   1100Hz     |  1700Hz     |     0.35   |     0.35 
     k (Key Pulse) |   1500Hz     |  1700Hz     |     0.35   |     0.35 
     h (Hangup)    |   2600Hz     |     0Hz     |     0.70   |     0
     
 It should be mentioned that this software was written in order to implement
a software version of the infamous bluebox, and it has been created for
educational purposes, only.

3.0 Building
/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/

--------------------------------------
3.1 majikhistle Application
--------------------------------------
From the MajikWhistle directory type 'sh buildMajikWhistle.sh.
The program, called majikWhistle will be created.

--------------------------------------
3.2 Rapid Prototype Applications
--------------------------------------
Change directory to rapidPrototype.  Type 'buildDtmf.sh'. The following
programs will be created in the rapidPrototype/ firectory:
dialer, dtmf, testMajik

/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/
4.0 Usage
/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/_/
To execute the majikWhistle program, type './majikWhistle'. Open up a
separate terminal and type 'netcat localhost 20330'. A welcome message will
be displayed, ans you can type help to view the list of commands.  For
example, to dial a number, type 'dial call k 1 (20)555-1212 s'. The
appropriate dial tones will be output by the sound card.

To execute the programs in the rapidPrototype directory, you can type:
./dtmf
or
./dialer
or
./testMajik

Each of these programs display usage information if you provide an
argument of -h.
